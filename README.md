# Computer Programming 1 - C++ Code Examples Repository
 
## Overview
 
This repository contains the source code examples, laboratory exercises, demonstrations, and programming activities discussed during our **Computer Programming 1** classes using **C++**.
 
The primary purpose of this repository is to provide students with a centralized collection of reference materials that demonstrate the fundamental concepts, logic-building skills, and programming techniques covered throughout the course.
 
Students may use these examples for:
 
* Reviewing classroom discussions
* Practicing programming concepts
* Understanding how programs are structured and how they run
* Preparing for laboratory activities and assessments
* Building their own small programs and projects
 
## Course Objectives
 
This repository supports the course objectives by providing practical implementations of the topics covered in class.
 
Students are expected to:
 
* Understand the basic concepts of computer programming and problem solving.
* Write, compile, and run C++ programs using an IDE.
* Use variables, data types, operators, and expressions correctly.
* Apply decision-making and repetition structures to control program flow.
* Break programs into reusable functions.
* Store and process collections of data using arrays and strings.
* Follow proper coding standards and good programming practices.
  
## Learning Outcomes
 
Upon successful completion of this course, students should be able to:
 
* Explain the basic structure and execution flow of a C++ program.
* Declare and use variables, constants, and data types appropriately.
* Accept user input and display formatted output.
* Use conditional statements (`if`, `if-else`, `switch`) to make decisions in a program.
* Use loops (`while`, `do-while`, `for`) to repeat tasks, including nested loops.
* Create and call functions with parameters and return values.
* Use one-dimensional arrays to store and process data.
* Debug and test programs to find and fix logic and syntax errors.
* Develop simple programs that solve real-world problems.
 
## Technologies
 
The examples in this repository may include:
 
* C++
* Visual Studio (Community Edition is free) or any standard C++ compiler

## How to Use
 
1. **Download or clone the repository.**
   To download: click the green **Code** button, then **Download ZIP**, and extract the folder.
   To clone using Git:
```
git clone https://github.com/flourwax/ComputerProgramming1-CPP.git
```
 
2. Open the desired example:
   * In Visual Studio, create a new **Console App (C++)** project and add the `.cpp` file to it, or
   * Compile it with your preferred C++ compiler.
3. Build and run the program.
4. Read the code, then experiment with modifications to strengthen your understanding.
   
## Notes for Students
 
* These examples are intended for educational purposes.
* Study the source code and understand how each concept is implemented.
* Type the code yourself instead of only copying and pasting it, because typing helps you learn.
* Avoid copying solutions without understanding the logic behind them.
* Try changing the inputs, conditions, and values to see how the output changes.
* Use the examples as references when completing laboratory exercises and programming projects.
